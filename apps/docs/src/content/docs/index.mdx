---
title: Engraver
description: Interactive, editable music notation for the web.
---

Engraver renders scores with [VexFlow](https://vexflow.com) and lets users input, select and edit notes with the mouse and keyboard, with built-in playback.

:::note
Engraver is in early development. The packages are not published to npm yet and the API will change.
:::

## Packages

| Package           | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `@engraver/core`  | Framework-agnostic score model, editing logic, rendering and player |
| `@engraver/react` | React component, providers and hooks                                |
