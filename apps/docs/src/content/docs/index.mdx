<Aside>
  Engraver is in early development. The packages are not published to npm yet and the API will
  change.
</Aside>

<CardGrid>
  <Card title="Editable" icon="pencil">
    Select measures and enter notes with the toolbar or keyboard shortcuts.
  </Card>
  <Card title="Playback" icon="rocket">
    Sampled instruments, loaded on demand, with a built-in player.
  </Card>
  <Card title="Framework-agnostic" icon="puzzle">
    A plain TypeScript core with React bindings. Vue and Svelte are planned.
  </Card>
  <Card title="SVG rendering" icon="document">
    Scores render to SVG through a bundled VexFlow fork.
  </Card>
</CardGrid>

## Packages

| Package           | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `@engraver/core`  | Framework-agnostic score model, editing logic, rendering and player |
| `@engraver/react` | React component, providers and hooks                                |
